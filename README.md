# Small Talk Warm-up: design boards

Static design boards for Small Talk Warm-up, a phone-first web app where adult professionals learning English (B1 to C1) warm up for small talk with Claire, an AI colleague.

Open `index.html` in a browser, or view the hosted version through GitHub Pages.

## Interactive demo

`demo/index.html` is a scripted, clickable version of the app: one chat in the hotel lift, a debrief built from the replies you choose, and the teacher view. Claire's replies are scripted, and the page says so. In the live prototype, Claude writes every reply. The demo is one self-contained file with no network calls apart from Google Fonts.

The learner in the demo, Lucía, is a fictional profile based on a real learner.

## Design boards
 Drag to move, scroll or pinch to zoom, or use the Screens, System and Fit all buttons.

Contents: scenario picker, settings sheet, four conversation states, debrief, history, session view, colour tokens and type scale, components, and the laptop layout.
